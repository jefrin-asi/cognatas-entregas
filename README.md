# Entregas del sistema Cognatas
`paquete.enc` es el sistema cifrado (AES-256). Instalar/actualizar en la PC:

    git clone https://github.com/jefrin-asi/cognatas-entregas.git && cd cognatas-entregas && bash instalar-cognatas.sh <clave>

Para una versión nueva: `cd cognatas-entregas && git pull && bash instalar-cognatas.sh <clave>`.
